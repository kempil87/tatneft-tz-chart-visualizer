# Tatneft Frontend TZ

SPA для ввода числовых параметров, визуализации на графике и импорта данных из CSV.

Тестовое задание на позицию фронтенд-разработчика Татнефть.

## Site - https://kempil87.github.io/tatneft-tz-chart-visualizer

## Запуск

Требуется Node.js 20+.

```bash
yarn
yarn dev
```

Сборка и проверка:

```bash
yarn build
```
