# Tatneft Frontend TZ

SPA для ввода числовых параметров, визуализации на графике и импорта данных из CSV.

Тестовое задание на позицию фронтенд-разработчика Татнефть.

## Site - https://kempil87.github.io/tatneft-tz-chart-visualizer

## Запуск

Требуется Node.js 22+.

```bash
yarn
yarn dev
```

Сборка и проверка:

```bash
yarn build
```

## Дополнительно:

Возможность восстановить данные после перезагрузки страницы
Сохранение состояния темы после перезагрузки и слушатель media-queries
